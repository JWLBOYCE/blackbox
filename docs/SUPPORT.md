# Blackbox Support

Blackbox is a local-first macOS flight logbook for macOS 14 or later.

## Before requesting help

1. Keep the original flight logbook or source database unchanged.
2. Create and verify an encrypted Blackbox backup before changing or restoring records.
3. Record the Blackbox version and build from Finder's Get Info panel.
4. Describe the steps that produced the issue and the expected result.

For public support, open a GitHub issue at https://github.com/JWLBOYCE/blackbox/issues. Never attach a real logbook, roster, database, export, backup, PDF, screenshot containing personal information, or backup passphrase.

For a vulnerability or privacy issue, use a private GitHub Security Advisory at https://github.com/JWLBOYCE/blackbox/security/advisories/new instead of a public issue.

## Important limitations

- Blackbox's completeness, consistency, recency, and report checks are aids for human review. They are not legal, regulatory, licensing, operator, or authority certification.
- Airport coordinates and route graphics are informational and must not be used for navigation.
- The user remains responsible for checking records against original evidence and applicable requirements before relying on or exporting them.
